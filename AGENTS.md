# Правила проекта

- Сначала прочитай корневой `README.md`. Полное ТЗ и архитектурные решения находятся в `./docs`.
- **Перед любой работой с Git обязательно прочитай `docs/git-process.md` целиком и строго следуй ему.** Это правило действует для каждого агента и каждой задачи в репозитории.
- Коммить каждый завершённый небольшой пласт отдельно, в формате Conventional Commits. Перед коммитом проверь сборку с предупреждениями как ошибками, тесты и отсутствие секретов в staged diff. Автор и коммиттер — владелец репозитория; не добавляй трейлеры соавторства или подписи инструментов.
- Сохраняй существующие изменения рабочего дерева и добавляй в коммит только файлы своей задачи.
