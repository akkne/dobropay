# ADR 0003: локальный симулятор

Для M1 адаптер `IPaymentProvider` возвращает устойчивый внешний ID попытки. Кнопки checkout формируют HMAC-подписанное событие и отправляют его через тот же входящий маршрут, который принимает событие провайдера. Это проверяет путь inbox/Worker без карточных реквизитов. Реальный адаптер и серверное уточнение статуса появятся после выбора провайдера.
