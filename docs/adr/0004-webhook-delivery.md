# ADR 0004: надёжная доставка

Событие бизнеса создаётся в outbox в транзакции перехода платежа. Worker создаёт доставку, затем фиксирует аренду перед HTTP-запросом. Ошибка приводит к повтору с тем же `event_id`; журнал хранит HTTP-результат каждой попытки. Получатель обязан дедуплицировать события. Для M1 URL фиксирован локальной настройкой; регистрацию произвольных адресов оставляем M2.
