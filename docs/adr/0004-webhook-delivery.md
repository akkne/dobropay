# ADR 0004: Асинхронная шина Kafka, Redis-лимитер и надёжная доставка Webhook

Переход платежа в терминальный статус порождает запись в `outbox_events`, которая публикуется в топик Kafka `dobropay.payment-events.v1` с ключом партиции `payment_id`. Сервисы `Notifications` и `Receipts` читают топик в своих consumer groups, фиксируя входящие события в собственных таблицах inbox до коммита offset. `Notifications` использует Redis для краткосрочного rate-limiting по магазину (с безопасным откладыванием при недоступности Redis) и доставляет webhook с подписью HMAC-SHA256 и экспоненциальными повторами.
