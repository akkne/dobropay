# ADR 0002: Работа с БД исключительно через EF Core и изоляция магазинов

Вся работа с PostgreSQL строится исключительно через **Entity Framework Core** (`DbContext`, `IEntityTypeConfiguration<T>`, LINQ и типизированные репозитории) без использования raw SQL. Изоляция данных между сервисами обеспечивается физическим разделением баз данных (Database-per-Service), а изоляция данных магазинов внутри каждого сервиса — фильтрацией по `ShopId` и составными ключами `(ShopId, PaymentId)` на уровне модели EF Core.
