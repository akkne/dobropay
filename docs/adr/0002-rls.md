# ADR 0002: Многоарендная изоляция магазинов через Row Level Security (RLS)

Во всех базах данных, хранящих сущности магазинов (`merchant_dev_db`, `payments_db`, `notifications_db`, `receipts_db`), включены `ENABLE ROW LEVEL SECURITY` и `FORCE ROW LEVEL SECURITY` с политикой `shop_id = NULLIF(current_setting('app.shop_id', true), '')::uuid`. Рабочие роли `<service>_runtime` не имеют `SUPERUSER` или `BYPASSRLS`. Каждый запрос или фоновая операция в коде открывает транзакцию через абстракцию `IDbSessionFactory` и устанавливает проверенный `shop_id` параметризованным вызовом `set_config('app.shop_id', ..., true)` на время транзакции.
