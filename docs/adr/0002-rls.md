# ADR 0002: изоляция магазинов

Все таблицы магазина используют `ENABLE` и `FORCE ROW LEVEL SECURITY`. API получает магазин из серверного ключа, checkout — из хеша токена. Проверенный `shop_id` задаётся локально в транзакции. Worker читает очереди межмагазинно под отдельной ролью, а изменения платежей выполняет в контексте конкретного магазина. Точные функции поиска работают как ограниченный bootstrap-владелец.
