# ADR 0001: общая БД и границы модулей

M0–M1 используют один API, один Worker и PostgreSQL. Владение таблицами задано в `docs/architecture.md`; статус платежа меняет только Payments. Это позволяет атомарно сохранить входящее подтверждение, платёж и outbox. Разделение процессов или БД рассмотрим после появления реальной нагрузки.
