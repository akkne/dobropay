# ADR 0001: Микросервисы и паттерн Database-per-Service

Вместо общей базы данных для микросервисов принят паттерн **Database-per-Service**: каждый доменный сервис с состоянием (`Auth`, `DeveloperApi`, `Payments`, `Notifications`, `Receipts`) работает со своим собственным физически изолированным контейнером PostgreSQL (`auth-db`, `merchant-dev-db`, `payments-db`, `notifications-db`, `receipts-db`), своими миграциями и ролями. Сервисы `MerchantAdmin` и `Email` не имеют собственных БД и взаимодействуют с владельцами данных исключительно через внутренние HTTP API с проверкой сервисного ключа и контекста магазина.
